# Expense Tracker

A simple Expense Tracker developed using Python.

## Features

- Add Expense
- View Expenses
- Search Expense
- Calculate Total Expense
- Delete Expense
- Exit

## Technologies Used

- Python

## How to Run

1. Open the project in VS Code.
2. Open the terminal.
3. Run `python expense_tracker.py`.
4. Select an option from the menu.
5. Enter the required expense details.

## Project Description

This project helps users manage their expenses by adding, viewing, searching, calculating total expenses, and deleting expenses.
